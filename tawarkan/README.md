# TawarKan demo (static export)

Static Next.js export of [arthursetiawan/tawarkan](https://github.com/arthursetiawan/tawarkan), published at:

**https://arthursetiawan.github.io/tawarkan/**

Rebuild from the app repo (`npm run build`) and replace this directory with `out/` when updating the demo. Config: `output: "export"`, `basePath`/`assetPrefix`: `/tawarkan`, `trailingSlash: true`.
