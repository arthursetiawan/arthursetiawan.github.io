Real engine endpoints

The production-style FastAPI service in arthursetiawan/automotive-dynamic-pricing-engine exposes the same contracts on live inference:

  • GET /health — liveness + model load status
  • POST /predict — win probability + raw recommended price
  • POST /optimize-price — clamped price with margin floor & tariff ceiling

This page never calls that API. The mock reimplements the published recommendation and clamping formulas on synthetic scores so the demo stays static on GitHub Pages.
