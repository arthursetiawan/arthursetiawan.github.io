Engine endpoints

The FastAPI service in arthursetiawan/automotive-dynamic-pricing-engine exposes:

  • GET /health — liveness + model load status
  • POST /predict — win probability + raw recommended price
  • POST /optimize-price — clamped price with margin floor & tariff ceiling

Live mode POSTs from this origin (https://arthursetiawan.github.io to the configured API host (CORS must allow it). Mock mode keeps the same contracts with synthetic scores when the API is offline or the base URL is still awaiting deploy.
